    Sobre mí

    Soy Full-Stack Developer (Java • Node.js • Python) con un enfoque sólido en el diseño, desarrollo e integración de aplicaciones web completas. A lo largo de distintos proyectos he construido servicios backend escalables, APIs seguras y frontends modernos, aplicando buenas prácticas, patrones de diseño y arquitecturas claras.

    Trabajo como Backend Developer y API Developer, desarrollando microservicios con Spring Boot, aplicaciones modulares en Node.js/Express, y soluciones basadas en Python + Flask. Tengo experiencia implementando autenticación JWT, manejo de roles, control de errores, integración con bases de datos MySQL y MongoDB, así como el diseño de modelos entidad-relación, normalización y consultas avanzadas.

    En paralelo, me desempeño como Frontend Developer (TypeScript + CSS), creando interfaces responsivas y dinámicas, optimizando la experiencia de usuario y manteniendo una línea visual moderna.
    I am a Full-Stack Developer (Java • Node.js • Python) with strong experience in building complete, scalable, and well-structured web applications. I have developed secure APIs, backend services, and modern frontends, applying clean architecture principles and best practices.

    As a Backend Developer and API Developer, I work with Spring Boot, Node.js/Express, and Python + Flask, implementing JWT authentication, role-based authorization, error handling, and database integrations with MySQL and MongoDB. I also specialize in database design, ER modeling, normalization, and advanced queries.

    On the frontend side, I work as a Frontend Developer (TypeScript + CSS), creating responsive and dynamic interfaces with a consistent and modern style.
