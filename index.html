En desarrollo

Turnos: plataforma de reservas white-label

Sistema de turnos multi-tenant para consultorios, peluquerías o estudios. Cada negocio configura su marca, horarios, servicios y profesionales sobre la misma instalación. Incluye reserva en pasos, cobro de señas con Mercado Pago y recordatorios por WhatsApp y email con n8n.

  • Capa de datos intercambiable (Airtable, Firebase o datos de prueba) detrás de un único punto de acceso: cambiar de proveedor no toca la interfaz.
  • Permisos por rol (paciente, profesional, administración) definidos en un solo archivo que usan la UI y el servidor.
  • Sesiones con cookie firmada con HMAC, contraseñas con scrypt y eventos firmados hacia n8n.
  • Entorno de pruebas con Mercado Pago y n8n simulados para recorrer el flujo completo sin cuentas reales.

Turnos para peluquería

Sistema web para reservar y administrar turnos. El cliente elige servicio y horario libre y recibe confirmación y recordatorio por correo; el administrador gestiona la agenda completa con métricas del negocio.

  • API en FastAPI con SQLAlchemy 2, migraciones con Alembic y autenticación JWT con dos roles.
  • Reglas de agenda validadas en el servidor: sin solapamientos, dentro del horario de atención y según la duración de cada servicio.
  • Automatizaciones en n8n: confirmación, recordatorio 24 h antes y aviso de cancelación.
  • Entorno completo con Docker Compose e integración continua con GitHub Actions.
